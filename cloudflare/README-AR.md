# مجموعة العلقمي — Cloudflare Admin + D1 (المرحلة الأولى)

## الموارد المنشأة فعلياً
- Worker: `alalqami-store-api`
- لوحة الإدارة (بعد إعداد الحماية): https://alalqami-store-api.awjnob1988.workers.dev/admin/
- فحص الربط: https://alalqami-store-api.awjnob1988.workers.dev/health
- قاعدة D1: `alalqami-store-db` (منفصلة عن دبي).
- قاعدة البيانات تضم 20 منتجاً مستورداً للمراجعة (active=0)، ولا يوجد كوبونات أو طلبات مضافة حتى الآن.
- ملفات المشروع محفوظة على فرع `alqami-admin-dev`، ولم يُغيّر موقع GitHub Pages الأصلي.

## خطوات الأمان المطلوبة قبل استخدام اللوحة
داخل Cloudflare > Workers & Pages > alalqami-store-api > Settings > Variables and Secrets:
1. أضف Secret نصي باسم `ADMIN_PASSWORD`: اختر كلمة مرور قوية وفريدة (20 حرفاً أو أكثر).
2. أضف Secret نصي باسم `AUTH_KEY`: سلسلة عشوائية مختلفة تماماً، 32 حرفاً أو أكثر، أنشئها عبر مدير كلمات المرور.
3. احفظ/انشر الإعدادات عند ظهور زر Deploy.
4. تأكد أن `/health` يعيد `admin_ready: true`، ثم افتح رابط /admin/ وسجل بكلمة مرور `ADMIN_PASSWORD`.

**لا ترسل الكلمات السرية عبر الدردشة ولا تضعها على GitHub.** لا تضف ربط WhatsApp قبل مراجعة رقم المتجر؛ الخيار `SHOP_WHATSAPP` يمكن إضافته لاحقاً كمتغير أو Secret وهو رقم دولي بلا +.

## ما هو الجاهز؟
- واجهة عربية بخط Zain وهوية العلقمي.
- إدارة أسعار المنتجات والخصومات والنشر (sale_price اختياري).
- إنشاء كوبونات بنسبة/مبلغ، بنطاق منتج أو أقسام أو المتجر كله، قيود للمدة والاستخدام والدمج.
- API عامة `GET /api/catalog` و`POST /api/quote` و`POST /api/order`.
- التسعير من قاعدة البيانات بالخادم وليس من أرقام العميل.
- حجز استخدام الكوبون بمعاملة D1 وTrigger لحماية الحد الأقصى.
- حفظ الطلبات ومنع إعادة إرسال نفس idempotency_key، وتقييد مبدئي لمحاولات تسجيل الدخول والطلبات.

## حدود الجاهزية
**المتجر الحالي لم يُربط بعد** بـ API الجديدة؛ الحفاظ على تجربة زبائن GitHub الحالية أولوية حتى إنهاء الإعداد والتجارب.
عند نشر المنتجات في D1 وحدها، لن تتغير بطاقات المتجر القديم تلقائياً. الربط النهائي مرحلة ثانية تشمل السعر المشطوب، إدخال كوبون في السلة، وتأكيد طلب واتساب.
أسعار الكتالوج مستوردة من بيانات سابقة وتحتاج تأكيد قبل تفعيل نشرها، ورقم واتساب يحتاج مراجعة.
لا تضع ADMIN_PASSWORD ولا AUTH_KEY في كود Worker أو المستودع. حساب Cloudflare Free له حدود طلبات/استعلامات يومية؛ لا يوقف مشروع D1 تلقائياً عند مرور أسبوع بدون زوار، لكنه ليس ضمان إتاحة غير محدودة.
