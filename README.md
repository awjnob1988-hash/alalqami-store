# مجموعة العلقمي — Al-Alqami Group

متجر عربي لعرض أجهزة تنقية وتحلية المياه، مع واجهة متجاوبة وتأثيرات ماء متحركة.

## المعاينة عبر GitHub Pages

1. افتح **Settings → Pages** داخل المستودع.
2. في **Build and deployment** اختر **Deploy from a branch**.
3. اختر الفرع **main** والمجلد **/(root)** ثم اضغط **Save**.
4. رابط المعاينة بعد النشر: https://awjnob1988-hash.github.io/alalqami-store/

توجد ملفات المعاينة في `index.html` مباشرة. الصور الأساسية مضمنة في الملف نفسه لسهولة النشر من دون إعدادات إضافية.

## قبل الإطلاق التجاري

- هذا إصدار **معاينة**، وليس متجراً نهائياً.
- يلزم تدقيق الأسعار وأسماء الموديلات والمواصفات وتوافر المخزون.
- بعض صور المنتجات صور مرجعية لماركات من جهات خارجية، وليست صور مخزون المجموعة؛ يلزم استبدالها بصور أصلية أو مصرح باستخدامها.
- يلزم التأكد من **رقم واتساب** وبيانات التواصل قبل استقبال طلبات حقيقية.
- لا توجد قاعدة بيانات للطلبات أو لوحة تحكم في هذه المرحلة. سلة الزبون محفوظة محلياً، وإكمال الطلب يتم يدوياً عبر تطبيق واتساب، والدفع عند الاستلام فقط.
- خدمة التركيب تظهر للطلبات داخل كربلاء، والتوصيل لبقية المحافظات.
